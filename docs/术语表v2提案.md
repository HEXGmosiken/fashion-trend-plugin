# 术语表 v2 提案：从"能认出来"到"能判定"

> 针对 `data/corpus/terms.json`（204 条）的体检结果与升级方案。
> 目标：不是把 204 变成 300，而是让每条词**可判定、可区分、可分析**。

---

## 一、体检结果（基于当前文件实测）

| 指标 | 实测 | 说明 |
|---|---|---|
| 总条数 | 204 | 板块：廓形 40 / 面料 40 / 色彩 38 / 风格 33 / 结构 31 / 场景 22 |
| 定义长度 | 中位 **8 字**，最短 4 字 | 大多是"X 的 Y"式短语，不是定义 |
| 无别名 | **100 条**（49%） | 别名是合并同义统计的唯一手段，缺一半等于没做归一 |
| 定义过短（<6 字） | **28 条** | 如"真丝：蚕丝织物"——无法据此判断 |
| 英文名重复 | **2 组** | `metallic` ×2、`resort` ×2 |
| 有判据 | **0 条** | 字段不存在，谁也说不清"看到什么才这么标" |
| 同板块包含关系 | 4 组 | 大衣/短大衣、长裙/中长裙、皮草/仿皮草、摇滚/垃圾摇滚——缺上下位结构 |

**结论：宽度够，深度不够。** 204 条覆盖了六个板块，但定义停在"词典式一句话"，
没有判据，所以同一个人两次标注可能不一致；没有易混词，所以近义词无法区分。

## 二、三个具体问题

### 问题 1：定义 ≠ 判据

现在写的是"斜裁：沿纱线斜向裁剪以贴合身体"——这是**定义**。
但标注时需要的是**判据**："布料上的条纹／织纹与地面呈约 45°，且下摆有明显波浪垂坠，才标斜裁。"

**定义回答"是什么"，判据回答"看到什么才这么标"。** 没有判据，标注就只能靠感觉。

### 问题 2：近义词没有区分机制

"褶皱 / 褶裥 / 抽褶"三条并存，但没有一行说明它们的差别。
结果：三个人标同一张图，可能标出三个词，统计直接失真。

### 问题 3：只有板块，没有层级

`board` 只到"结构 / 面料"这一层，没法做"袖型"这一级的聚合分析。
比如想问"这一季袖型整体在变宽吗"，现在做不到——因为袖型不是一个可聚合的组。

## 三、字段提案（在现有 5 个字段上加 3 个）

```jsonc
{
  "zh": "插肩",                     // 现有
  "en": "raglan sleeve",           // 现有
  "aliases": ["插肩袖", "raglan"],  // 现有
  "def": "肩线从领口斜向下连到腋下的袖型，肩部没有横向拼缝",  // 现有，写长一点
  "board": "construction",         // 现有
  "parent": "袖型",                 // 新增：上位类，用于聚合
  "criterion": "肩部看不到横向拼缝，拼接线从领口斜到下腋", // 新增：判据
  "confusable": "落肩（肩线整体下移，是横向的；插肩是斜线）"  // 新增：易混词
}
```

三个新字段的作用：

| 字段 | 解决什么 | 谁受益 |
|---|---|---|
| `parent` | 能按"袖型 / 领型 / 门襟"聚合分析 | 报告能做"袖型整体在变宽"这类结论 |
| `criterion` | 标注有一致标准，可复核 | B 的审计规则、人工抽查 |
| `confusable` | 近义词能分清 | 减少同义不同标 |

## 五、扩展计划（204 → 271，本批补 67 条）

不做全面铺开，只补最能拉开分辨率的两个板块：

| 板块 | 现有 | 补 | 重点 |
|---|---|---|---|
| 结构工艺 | 31 | +43 | 袖型（插肩/装袖/泡泡袖）、领型（青果领/戗驳领）、门襟、分割（育克/公主线）、缝制（明线/包边/嵌线） |
| 面料肌理 | 40 | +24 | 羊毛类（精纺/华达呢/麦尔登）、棉类（府绸/牛津纺/丹宁）、再生纤维（铜氨/醋酸/莫代尔）、表面肌理（提花/烂花/压皱） |

每条必须七栏齐全，**判据和易混词缺一不收**——这是验收标准。

---

## 六、验收标准（可检查）

1. 新增 40 条，字段完整率 100%；
2. 每条 `criterion` 能回答"看到什么才这么标"，不含"高级感""有设计感"这类词；
3. 每条 `confusable` 至少指出一个近义词并说明差别；
4. 对现有 28 条短定义补写到 15 字以上；
5. 补 100 条缺失别名中的至少 40 条；
6. 修掉 `metallic`、`resort` 两组英文重名。

---

## 七、给团队的一句话

> 术语表的价值不在条数，在**判据**。
> 204 条没有判据，等于 204 个只能意会的词；300 条都有判据，才是 300 个能对齐的观察维度。
