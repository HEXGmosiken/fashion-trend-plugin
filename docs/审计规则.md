# 审计规则

运行 `npm run audit` 检查示例台账。检查自己的数据时，传入该批证据、其冻结命题和对应的来源注册表。

```sh
npm run audit -- --input data/evidence.json --claims data/claims.json --sources data/sources.json
```

错误级问题会使 `audit` 返回退出码 1。每条审计记录都有代码、说明、关联编号和处理建议。完整分析的 `report.json` 将这些记录写入 `audit` 数组。

## 规则清单

| 代码 | 级别 | 触发条件 | 处理建议 |
| --- | --- | --- | --- |
| `E_UNKNOWN_SOURCE` | 错误 | 证据的 `sourceId` 在来源注册表中不存在 | 补登记来源或更正编号 |
| `W_FUTURE_DATE` | 警告 | 发布日期晚于审计日期 | 查原文后修正发布日期 |
| `I_DATE_ESTIMATED` | 提示 | `dateEstimated` 为 `true` | 找到原文日期后补录并取消估算标记 |
| `W_ACCESS_BEFORE_PUBLISH` | 警告 | 抓取日早于发布日期 | 核对并修正填错的日期 |
| `E_SEASON_MISMATCH` | 错误 | 标为 A 或 B 的证据，其主题季与该窗口在所有命题中的主题季都不一致 | 核对原文主题季及手工窗口标记 |
| `W_SHORT_EXCERPT` | 警告 | 摘录去掉首尾空白后少于 20 个字符 | 补录编码所依据的完整原文句子 |
| `I_DUP_URL` | 提示 | 规范化后的链接相同，重复记录被剔除 | 核对保留记录的来源与编码 |
| `W_DUP_TITLE` | 同集团为提示，跨集团为警告 | 标题相似度命中对应去重规则，重复记录被剔除 | 对照原文，核实版本重复或转载关系 |
| `E_UNFROZEN_RULE` | 错误 | 计算层接收到未通过编码规则有效性检查的命题 | 先写清何时计为 `true`、`false` 或保留未编码，再编码和重跑 |
| `W_NO_SCOPE` | 警告 | 命题的品牌列表与来源类型列表都为空 | 补充可检查的范围，并写明样本适用边界 |
| `W_SMALL_N` | 警告 | A、B 任一窗口的有效样本量少于 `minN` | 按原口径补足两窗的独立样本 |
| `E_NO_SUPPORT` | 错误 | 生成了结论但缺少支撑引用。单向命题在 B 窗没有任何符合假设方向的观测时，反证可作为复核依据 | 核对编码和引用，补充合格的支撑或反证 |
| `I_CI_OVERLAP` | 提示 | 两窗均有有效样本，且 Wilson 区间相交或边界相接 | 连同样本量和区间报告结果，将幅度作为描述性数字 |
| `E_DANGLING_REF` | 错误 | 支撑或反证引用的编号在去重后台账中不存在 | 换成台账保留的证据编号 |
| `W_SPONSORED_IN_SUPPORT` | 警告 | 支撑列表含 `isSponsored: true` 的条目或 `type: "brand"` 的来源 | 把投放内容移为背景，用独立来源替换 |
| `W_TIER3_DOMINANT` | 警告 | 去重后三级和未登记来源的条目合计超过 50% | 补充一手资料或专业媒体，报告来源构成 |
| `W_SAMPLE_OUT_OF_SCOPE` | 警告 | A/B 窗中已做布尔编码的候选证据，品牌或来源类型超出命题允许列表 | 核实证据身份和冻结口径 |
| `E_SAMPLE_OUT_OF_SCOPE` | 错误 | 结论的任一支撑或反证引用超出命题品牌或来源类型范围 | 移除引用，按冻结口径重新统计 |
| `W_WINDOW_MISMATCH` | 警告 | 已做布尔编码的 A/B 候选证据主题季不符，或发布日期落在该窗起止日期之外 | 核对主题季和发布日期，重新归类 |
| `E_WINDOW_MISMATCH` | 错误 | 支撑或反证引用标为背景窗 X，或主题季或日期与其 A/B 窗不符 | 移除或更正错配引用后重新统计 |
| `W_PROMO_EXCLUDED` | 警告 | 已对至少一个命题编码的 A/B 候选证据被标为投放或来自品牌型来源 | 将此类内容作为背景资料保留 |
| `E_UNKNOWN_CLAIM` | 错误 | 结论没有对应的命题编号 | 更正 `claimId` 或补齐命题 |
| `E_UNCODED_REF` | 错误 | 支撑或反证引用缺少该命题信号的布尔编码 | 对照原文补做编码，或移除引用 |

## 判断口径

- 窗口日期包含起止日。A、B 可覆盖部分相同日期，证据必须同时满足所标窗口的日期范围与主题季。
- 非空的 `sampleScope.brands` 和 `sampleScope.sourceTypes` 分别限制品牌及来源类型。品牌匹配会归一化全半角、大小写和空白。
- `sampleScope.include` 和 `sampleScope.exclude` 是给编码人员的文字标准。人工复核需确认全文、图像、分析单位及这些条件。
- `isSponsored: true` 或来源类型为 `brand` 的证据会从分母、支撑和反证剔除。品牌名是文章的报道对象，单有品牌名仍可作为独立媒体证据。
