# 去重阈值校准

用 [16 对公开服装稿件的题名与链接](../tests/fixtures/dedup-calibration.json) 复测。标注依据是媒体页面上的首发链接、通讯稿署名或独立出版信息。把共享同一编辑稿件的 Vogue 各地区版本归入同一来源组，转载 Reuters 或新华社通讯稿的不同媒体各归自己的出版组。样本只保存元数据。项目原始的 50 篇语料未随仓库提供，以下结果适用于这个人工挑选的小样本。

## 测试结果

| 稿件对 | 数量 | 原实现 | 本次 |
| --- | ---: | ---: | ---: |
| 同一 URL | 1 | 1 命中 | 1 命中 |
| 同一来源组的版本 | 6 | 1 命中 | 2 命中 |
| 跨媒体转载 | 3 | 2 命中 | 3 命中 |
| 应保留的独立稿件 | 6 | 5 保留、1 误并 | 6 保留 |

- **0.85（同组）**。统一常见撇号后，M1 从 0.800 升至 1.000。M3–M6 改写标题后的相似度在 0.214–0.500，和独立稿件 N6 的 0.400 交叠。大幅降低门槛仍难区分这些稿件，因此保留 0.85。看到首发链接时，可人工确认并在台账中保留一条代表记录。[British Vogue](https://www.vogue.co.uk/article/milan-fashion-week-spring-summer-2025-debrief) · [Vogue Scandinavia](https://www.voguescandinavia.com/articles/vogues-five-minute-fashion-month-debrief-milan-ss25-edition)
- **0.92（跨组）**。统一拉丁字母重音后，C1 从 0.846 升至 1.000。三个已标注转载均达到原门槛，没有证据支持放宽。N3 的两个媒体标题完全相同，作品不同。跨组标题匹配同时要求至少一方标为 `reprint` 或 `translation`。未知转载来源或翻译改写由编辑复核。[MarketScreener](https://www.marketscreener.com/news/hermes-shows-airy-knits-and-slit-skirts-in-spring-summer-2027-collection-ce785ddbdd80f626) · [bdnews24](https://bdnews24.com/Fashion/01sbs9peek) · [Vogue](https://www.vogue.com/fashion-shows/spring-2027-ready-to-wear/hermes) · [WWD](https://wwd.com/fashion-news/shows-reviews/gallery/hermes-spring-2027-ready-to-wear-collection-1239308039/)

比较未舍入的 Jaccard 相似度，恰好等于门槛也可合并。先比较规范化 URL，再比较同组标题，最后比较跨组标题。两条记录的主题季都已知且不一致时，只接受同 URL 判定。保留记录优先选独立、未投放稿，优先级相同再按原创性和录入顺序决定。可通过去重记录中的 `duplicateOf` 追溯归并顺序。
